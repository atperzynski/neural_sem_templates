This folder holds the model in lavaan syntax (`model.lav`), the lavaan script that refits the model
and compares lavaan's numbers with the app's (`lavaan_check.R`), and the Mplus input file
(`model.inp`), which has not yet been run in Mplus. A change to the model is made in HOT-NUX-SEM,
or by editing `model.lav` and opening the project again in the app, so that the three files stay
in step.
